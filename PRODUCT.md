# Alchemmist Docs

A reusable Hugo documentation theme for independent documentation repositories.
Readers browse folders, read notes, follow page outlines, and search local content.
The theme is published as github.com/alchemmist/hugo-docs and uses the pinned
hugo-content module for typography, code, mathematics, diagrams, and media.

The existing white, minimal visual system is intentional. The exampleSite contains
public demonstration notes, while starter contains a clean project template.
Neither directory is mounted as content when another site imports the theme.

Support Russian and English interface labels, configurable branding, subpath
hosting, accessible navigation, and Docker Compose deployment. Runtime content,
fonts, and scripts stay local; no search backend or CDN is required.
